# Patchline UI demo

Изолированные примеры: snapshot-правки, многофайловый patch, пакет точных замен, stale guard и диагностика.

## Status

- Currency formatting: implemented.
- Discount calculation: implemented.
- Discount limits: clamped to 0–100%.

Run the checks with `node patchline-ui-demo/check.mjs`.
