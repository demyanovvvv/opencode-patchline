# Patchline 1.4.0

## English

This release unifies project/global installation and removal and adds verified
original-host recovery and project-scoped LSP management.

### Changes

- Shell and PowerShell wrappers use the adjacent built release/checkout package,
  preserve arguments/cwd/exit codes, and do not fetch a CLI from npm.
- New `--project`, `--cwd`, `--package`, `--help`, `--no-host`, `--no-lsp`,
  `--keep-deps` and `--restore-host` flags; installation now supports `--dry-run`.
  Values accept `--flag=value`; malformed/conflicting flags fail before changes.
- `--local --global` remains compatible: local selects the source, global the scope.
- Immutable original OpenCode backup, SHA-256 checks, shared-host owner tracking,
  per-binary locking and guarded restoration of unchanged owned update preferences.
- State changes during confirmation are preserved; Bun installed during host
  preparation is recorded and cleaned up on failure.
- Project language/server discovery, explicit `lsp check`/`lsp setup`, managed
  pinned server recipes and connection-aware status. Disabled/custom LSP remains.
- Conversation renderer for `patchline_lsp_status`; canonical fixture paths for
  Windows short-path and macOS temporary-directory aliases.

### Installation and upgrade

Download `opencode-patchline-1.4.0.tgz` and `SHA256SUMS.txt`, verify the SHA-256,
extract to a permanent directory, then run `npm install --omit=dev` inside
`package/`. From the target project run the adjacent `install.sh --project
--lang en`, or use `--cwd <project>`. For all projects use `--global --yes`.
Windows uses `install.ps1` with the same flags. Restart OpenCode afterwards.

Upgrading from 1.3.x uses the new package's installer in each affected scope and
preserves the installed upstream OpenCode version. Keep old package directories
while another scope still references them. Plain CLI `install --local` remains
available. Full host provisioning requires Git/Bun; use `--no-host` to skip it.

### Removal and recovery

Run the matching `uninstall.sh`/`uninstall.ps1` with the same scope; start with
`--dry-run`. `--keep-deps` preserves package dependencies. Regular removal leaves
the shared integrated host. `--restore-host` restores the saved original version
only if its hashes/ownership are valid and no other recorded installation remains.
User-changed update settings are preserved. Legacy installations without a
verified original cannot use rotating backups as evidence and require manual
OpenCode repair. Managed LSP caches and shared OpenCode caches are retained.

### Verification

Release gates cover typecheck, unit tests/coverage, lint, build, doctor, benchmark,
package/plugin/installer/LSP/TUI/Hashline smokes and dependency audit. New smoke
gates exercise project/global wrappers and real-native binary restoration in
isolated directories. Local Windows x64: 467 tests passed, one platform test
skipped; coverage 83.67% statements, 89.04% lines; typecheck, lint, build, doctor,
benchmark, package/plugin/installer/LSP/TUI/Hashline smokes and audits passed.
Doctor reports the expected running-host 1.3.0 / package 1.4.0 mismatch.
The GitHub Actions run attached to this tag records the
Linux release-gate result; the CI matrix reports Windows/Linux/macOS separately.
Local verification does not rebuild the full integrated UI host or include an
interactive UI update click-through.

See the [English guide](../../README.md), [upgrade policy](../operations/upgrade-policy.md)
and [removal instructions](../operations/uninstallation.md).

## Русский

Релиз объединяет установку и удаление в проектной/глобальной области и добавляет
проверенное восстановление исходного хоста и проектное управление LSP.

### Изменения

- Shell/PowerShell-скрипты используют соседний готовый пакет релиза или checkout,
  сохраняют аргументы, рабочий каталог и код завершения, не загружают CLI из npm.
- Добавлены `--project`, `--cwd`, `--package`, `--help`, `--no-host`, `--no-lsp`,
  `--keep-deps`, `--restore-host`; `--dry-run` работает и для установки.
  Поддерживается `--флаг=значение`; конфликтующие параметры отклоняются до изменений.
- `--local --global` совместим: local выбирает источник, global область.
- Неизменяемая исходная копия OpenCode, SHA-256, учёт владельцев общего хоста,
  блокировка и защищённый возврат неизменённых настроек обновления.
- Сохраняются изменения state во время подтверждения; Bun, добавленный при
  подготовке хоста, учитывается и удаляется при сбое.
- Обнаружение проектных языков/серверов, `lsp check`/`lsp setup`, закреплённые
  управляемые серверы и отдельная проверка соединения. Custom/disabled LSP сохранены.
- Карточка `patchline_lsp_status`; канонические тестовые пути для Windows/macOS.

### Установка и обновление

Скачайте `opencode-patchline-1.4.0.tgz` и `SHA256SUMS.txt`, проверьте SHA-256,
распакуйте в постоянную папку и выполните `npm install --omit=dev` внутри
`package/`. Для проекта используйте `install.sh --project --cwd <проект> --lang ru`,
для всех проектов `--global --yes`. На Windows запускайте `install.ps1` с теми же
флагами. Полностью перезапустите OpenCode.

Обновление с 1.3.x выполняется новым установщиком в каждой нужной области,
сохраняя upstream-версию OpenCode. Старый каталог сохраняйте, пока на него
ссылается другая область. Для полного хоста нужны Git/Bun; `--no-host` пропускает
его подготовку. Старый интегрированный хост не получает исходную копию задним числом.

### Удаление и восстановление

Запускайте `uninstall.sh`/`uninstall.ps1` в той же области; сначала `--dry-run`.
`--keep-deps` сохраняет зависимости. Обычное удаление оставляет общий хост.
`--restore-host` возвращает сохранённую исходную версию при проверенных хешах,
владении и отсутствии других записанных установок. Изменённые пользователем
настройки обновлений сохраняются. Legacy без доказанной исходной копии требует
ручного восстановления OpenCode; `.patchline-previous` не доказывает stock-версию.
Кэши управляемых LSP и OpenCode сохраняются.

### Проверка

Релизные gates включают typecheck, тесты/coverage, lint, build, doctor, benchmark,
package/plugin/installer/LSP/TUI/Hashline smoke и аудит зависимостей. Новые smoke
проверяют обе области и восстановление native-файла в изолированных папках.
Локально Windows x64: 467 тестов пройдены, один платформенный тест пропущен;
coverage 83,67% statements и 89,04% lines; typecheck, lint, build, doctor,
benchmark, package/plugin/installer/LSP/TUI/Hashline smoke и аудиты пройдены.
Doctor показывает ожидаемое расхождение работающего хоста 1.3.0 и пакета 1.4.0.
GitHub Actions у тега фиксирует Linux-проверки релиза; CI отдельно показывает
результаты Windows/Linux/macOS. Локально не выполняется полная пересборка
интегрированного UI-хоста и интерактивное нажатие UI-обновления.
