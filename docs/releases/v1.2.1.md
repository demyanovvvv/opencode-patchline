# Patchline 1.2.1

[English guide](https://github.com/demyanovvvv/opencode-patchline/blob/v1.2.1/README.md) · [Русское руководство](https://github.com/demyanovvvv/opencode-patchline/blob/v1.2.1/README.ru.md) · [Changelog](https://github.com/demyanovvvv/opencode-patchline/blob/v1.2.1/CHANGELOG.md)

## English

### Versions

- Patchline: **1.2.1**
- OpenCode release baseline: **1.18.35**
- Integrated host for this pair: **1.18.35+patchline.1.2.1**

### Changes

- Preserved native OpenCode `apply_patch`; Hashline editing uses
  `patchline_apply_patch`, with snapshot invalidation around native patches.
- Hardened exact deletions, bounded read ranges, permission-aware external paths,
  mixed line-ending preservation and shell-write detection.
- Added compensating installer rollback and versioned ownership metadata.
- Added adaptive/Hashline conversation slots and bounded diffs.
- Restructured English and Russian README navigation and added practical usage
  guides. Release history now lives in the changelog and release notes.
- Distributed an installable GitHub package archive and SHA-256 checksum without
  requiring an npm registry publication.

### Install or update

Download `opencode-patchline-1.2.1.tgz` and `SHA256SUMS.txt` from this release.
Extract into a permanent directory, then run:

```bash
cd patchline-1.2.1/package
npm install --omit=dev
node dist/cli.js doctor
```

For the integrated Windows x64 host (OpenCode, Git and Bun required):

```bash
node dist/cli.js install --local --global --yes --lang en --opencode-version 1.18.35
```

For other platforms, use the manual file-URL registration in the English guide.
Fully restart OpenCode. Existing Hashline `apply_patch` calls must be renamed to
`patchline_apply_patch`; native standard patches keep the `apply_patch` name.

### Verification and limitations

Local verification passed: typecheck, 379 tests (2 skipped), coverage, lint,
build, doctor, benchmark, plugin/package/Hashline/TUI/install/lifecycle/LSP smoke
checks. Dependency audit: zero vulnerabilities. GitHub Actions jobs could not
start because of the account billing/spending limit; cross-platform CI results
are unavailable. The archive was built and published from the verified checkout.

Integrated-host provisioning currently supports Windows x64 and builds from
source using Git/Bun. The package archive is not a prebuilt OpenCode executable.
Cross-component recovery and ownership-aware legacy cleanup remain pending.
Uninstall does not restore the official executable or update preference.

## Русский

### Версии

- Patchline: **1.2.1**
- Базовая версия OpenCode: **1.18.35**
- Интегрированный хост для этой пары: **1.18.35+patchline.1.2.1**

### Изменения

- Сохранён обычный `apply_patch` OpenCode; Hashline выполняется через
  `patchline_apply_patch`, а обычные patch инвалидируют затронутые snapshot.
- Усилены точные удаления, ограниченные диапазоны чтения, проверка разрешений
  внешних путей, сохранение смешанных окончаний строк и обнаружение shell-записи.
- Добавлены компенсирующий rollback установщика и версионированные данные владения.
- Добавлены adaptive/Hashline-карточки и ограниченные diff.
- Перестроены README на английском и русском, добавлены навигация сверху и
  практические инструкции. История изменений перенесена в changelog и релизы.
- Подготовлены устанавливаемый GitHub-архив и SHA-256 checksum без обязательной
  публикации в npm.

### Установка или обновление

Скачайте `opencode-patchline-1.2.1.tgz` и `SHA256SUMS.txt` из этого релиза.
Распакуйте в постоянную папку и выполните:

```bash
cd patchline-1.2.1/package
npm install --omit=dev
node dist/cli.js doctor
```

Для интегрированного хоста Windows x64 (нужны OpenCode, Git и Bun):

```bash
node dist/cli.js install --local --global --yes --lang ru --opencode-version 1.18.35
```

На остальных платформах используйте ручное подключение через file URL из
русского руководства. Полностью перезапустите OpenCode. Старые Hashline-вызовы
`apply_patch` переименуйте в `patchline_apply_patch`; обычные patch сохраняют имя.
