# Module Map

Status: Accepted

| Module | Responsibility |
|---|---|
| `compatibility` | Runtime and dependency capability reports |
| `workspace` | Canonical paths, worktree identity, boundary enforcement |
| `preservation` | Raw UTF-8 bytes, BOM and line-ending round trips |
| `snapshot` | Session/worktree isolated observed-state history |
| `editing` | Exact edits, Hashline patches and multi-file preflight |
| `guards` | Existing-write, generated-file and unsafe-tool protection |
| `search` | Textual, structural and semantic routing |
| `validation` | Diagnostics and proportional command selection |
| `telemetry` | Local bounded event and task metrics |
| `tools` | OpenCode tool schemas and compact output formatting |
